# Top-Book-Final-Project---CS-193

A Java program that lets you get the top 15 book recommendations for a genre over the terminal.

## The Problem

I personally read a lot of books, and it can take a lot of time to search up lots of reviews. I am trying to make a simple way to track down information about the top books at the current time. Instead of having to manually search it all up, it can be there easily.
